# 📊 GitTrending-Daily

> 🏆 **每日 GitHub Trending 热门仓库中文日报** — 每天自动抓取 GitHub 最火的前 20 个项目，生成一份好看的中文日报。

每天早上花 3 分钟，就知道技术圈今天在关注什么。开源免费，Fork 即用。

## ✨ 特色

- 📥 **每日自动抓取** GitHub 最热门的 20 个仓库
- 🇨🇳 **中文阅读友好**，快速浏览不费力
- 🌐 **在线浏览**，无需安装，打开即看
- 🔄 **每天 UTC 01:12（北京时间 09:12）** 自动更新
- 🏷️ **标签分类**，一眼看出项目领域
- 🆓 **开源免费**，Fork 就能拥有自己的日报

## 🎯 自己部署一份

Fork 这个仓库，GitHub Actions 自动启用，什么都不用配置。

```bash
# 1. 点击右上角 Fork 按钮
# 2. 进入 Actions 选项卡，启用 Workflows
# 3. 等待第一次运行完成（每天 UTC 01:12 自动触发）
# 4. 访问 https://你的用户名.github.io/GitTrending-Daily/
```

> 也可以手动触发：进入 Actions → 每日抓取 GitHub Trending → Run workflow。
